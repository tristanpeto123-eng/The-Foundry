# The Foundry v7 — Authored Machine Assemblies

Six distinct GLB assets are bundled under `assets/`. These are generated, exportable triangular meshes with named components, not image-only mockups. Each has a fabricated frame, operator HMI, safety equipment, and function-specific mechanical assemblies.

They are loaded additively over the v6 fallback geometry to preserve the existing functioning scene; the next iteration should remove occluded fallback components and refine material/animation integration. This is a genuine asset-pipeline step, **not** a completed cinematic-quality mesh/material pass.

No live trading integration.
